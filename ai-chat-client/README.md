# Branch Mind application

See the [project README](../README.md), [中文说明](../README.zh-CN.md), and [usage/deployment guide](docs/BRANCH_MIND.md).

Requires Node.js 22+. Run `npm ci`, `npm run dev`, then open http://localhost:1666. Configure your own model API key in Settings. This repository contains no usable credentials or user learning data.
