# Branch Mind 使用与部署

Branch Mind 基于 [Prompt Tree](https://github.com/yxp934/Prompt-Tree) v0.7.0，保留模型配置、教材附件、上下文画布和长期记忆功能，增加专门的学习工作台。

## 本机运行

需要 Node.js 22 或更新版本。项目目录为 `ai-chat-client`。

```sh
npm install
npm run dev
```

打开 http://localhost:1666。首次进入「模型与记忆设置」配置自己的模型服务和 API 密钥。支持上游已有的 OpenAI 兼容接口；本地模型需要可供服务器访问的兼容服务。

稳定使用时执行：

```sh
npm run build
npm start
```

## 主线与答疑

1. 点击「新建学习主题」，在弹窗中输入课程主题、“我需要学什么”和“我现在掌握什么”（可写零基础），再点击「确认主题并创建章节」。输入前不会调用模型。
2. 默认自动生成课程章节；点击章节，用「创建分支」逐层细分，或用「开始学习」生成本节讲义。
3. 任一讲义下点击「单独答疑」，输入问题标题。新分支继承来源处的上下文，界面只展示该答疑的交流。
4. 答疑中还能继续分出答疑，保留父级答疑的位置。
5. 点击「返回主线」或「返回上级答疑」回到保存的位置。主线不会包含答疑原始消息。
6. 「标记已解决」只是人工状态，允许继续追问，不代表自动验证掌握。

一个课程对应一条主线，主线下有独立章节树，不设固定细分层数上限；章节讲义可单独分出答疑，答疑也支持多层嵌套。当前未实现自动检查学生是否掌握先修知识。

## 每份讲义的风格

右侧「讲义与记忆」设置当前分支的默认风格：严谨讲义、直觉理解、精简复习、自定义。可选择专业术语附英文括注，并填写补充要求。

输入框上方「本次讲义风格」可覆盖下一份讲义；选择自定义时可填写这一次的专用要求。覆盖在成功生成后清除。每份讲义保存生成时的风格，可以导出 Markdown，数学公式以 LaTeX 保留。切换风格不会自动改写旧讲义。

严谨风格采用正式教材式写作：加粗主题标题，以及「定义 1（中文术语，English Term）：……」等概念条目。先给适用对象与条件，再陈述结果和必要推导；不机械凑齐栏目，不输出寒暄、鼓励、口语铺垫或重复总结。详见 `docs/LECTURE_STYLE.md`。最终内容依赖所接模型，风格约束不是数学正确性的保证。

## 共享记忆与符号

「课程共享符号约定」在本课程每次对话请求中加载，包括答疑。不同课程可有不同约定。

讲义下「保存共享笔记」会打开确认编辑框。将临时推测改成你确认的结论后再共享，主线及同课程答疑均会读取它。笔记保留来源，能回看原始对话；移除共享不删除原始讲义。

上游用户档案、文件夹文档、自动记忆提取、记忆检索等功能仍在「模型与记忆设置」及「上下文与树状画布」。自动提取需要配置对应模型，可能增加 API 调用。课程共享笔记与上游自动记忆是不同机制。

## Windows、Mac、Android

当前交付为响应式 Web 应用及 PWA，一套代码供三端使用。生产版本含 manifest、图标、服务工作线程，支持通过兼容浏览器的「安装应用」入口安装。Android 安装及非 localhost 的 PWA 需要 HTTPS。当前没有打包原生 `.exe`、`.dmg` 或 `.apk`。

本地数据以浏览器来源区分：`localhost:1666`、`127.0.0.1:1666`、不同域名或端口是不同存储空间。请固定访问地址，或使用备份/同步迁移。浏览器缓存被清理也可能删除学习记录。

离线可查看已缓存界面和本机学习数据；AI 调用、同步和在线工具仍需要相应服务可达。服务工作线程不缓存 API、连接页和口令响应。

## 多端同步部署

需要一台各设备都能访问的长期运行服务器，或始终在线的电脑；无需为每台设备安装 Node.js。

在服务器设置 `BRANCH_MIND_SYNC_TOKEN` 为至少 24 位的随机口令。配置该变量后，整个学习空间及模型/工具 API 都要求先连接口令，避免直接开放 AI 和本机工具接口。建议用密码管理器生成口令。

macOS / Linux 的示例（替换口令）：

```sh
export BRANCH_MIND_SYNC_TOKEN='replace-with-your-long-random-token'
export BRANCH_MIND_DATA_DIR='/absolute/path/to/private-study-data'
npm run build
npm start
```

Windows PowerShell：

```powershell
$env:BRANCH_MIND_SYNC_TOKEN='replace-with-your-long-random-token'
$env:BRANCH_MIND_DATA_DIR='C:\BranchMindData'
npm run build
npm start
```

通过 HTTPS 反向代理连接这个服务。反向代理应保留原始 Host 并设置 X-Forwarded-Proto；也可设置 `BRANCH_MIND_PUBLIC_ORIGIN=https://你的域名` 明确指定允许的浏览器来源。在每台设备打开同一 HTTPS 地址，输入口令，然后安装 PWA。服务器为个人单空间设计，不支持多用户隔离。服务器主机能够读取同步数据；这里未实现端到端加密。

1. 第一台有学习内容的设备点击「上传本机」。
2. 另一台设备点击「下载最新」，确认替换；操作会先导出该设备已有数据的备份。
3. 每次换设备前上传，换到另一设备后下载，再开始编辑。
4. 若两台设备都编辑，服务器拒绝旧版本上传。先导出双方备份，决定保留哪份内容，再下载最新；第一版没有自动合并分支。

同步包括对话、课程/答疑结构、讲义风格、符号约定、共享笔记及上游记忆数据；不包括本机输入草稿以及 localStorage 中的 API 密钥、模型配置和工具密钥，各设备需单独配置。文本中手动写入的密钥不会自动脱敏。

服务器将快照保存为 `study.json`，用原子替换和写锁避免并发覆盖。一次备份最多 20MB。必须给数据目录配置持久磁盘并备份，不适合使用会随实例销毁的临时文件系统。异常终止遗留 `sync.lock` 时，确认没有写入任务后删除这个锁目录，再重试。

## 数据备份

「导出备份」生成 Branch Mind JSON，不包含模型密钥配置。导入会校验格式，在单个 IndexedDB 事务中替换全部学习数据，且先导出本机快照。保留备份文件，不要仅依赖浏览器存储。

## 2026-10-05 界面与模型更新

先使用内置 imagegen 生成功能绘制完整桌面设计，再用 React、SVG 和 CSS 复刻。设计草图保留在开发者本地；发布仓库仅提供可运行的界面源码。界面采用浅灰白、石墨文字和单一蓝色强调；学习分支以连线呈现，笔记规则、共享记忆及同步改为按需打开的抽屉。输入区集中放置模型和单份讲义风格选择；支持手机导航、深色外观及键盘操作。

新设备默认使用 `deepseek-flash`，服务地址 `https://api.deepseek.com`；设置中预置 DeepSeek Flash 和 DeepSeek V4 Pro。根据 DeepSeek 官方当前文档配置：https://api-docs.deepseek.com/ 。在「设置」的 DeepSeek 服务商中添加自己的 API 密钥即可使用。用户已有明确模型选择和服务地址会保留；未配置的旧默认会切换至 DeepSeek。真实 API 调用需密钥；最初的界面验证使用模拟请求，后续已通过用户授权的真实 API 集成测试。



## 自动章节与连接修正

新建课程先弹出主题输入框，确认主题后自动请求课程大纲并创建第一层章节。空白学习空间不会直接规划未命名课程。下方自由输入框专用于答疑：从主线或章节输入问题时自动创建独立答疑，已有答疑中则继续追问；即使问题含有“创建章节”等文字，也不会触发课程规划。点击章节后，用「继续细分」创建下一层；模型判断已足够细时仍保留细分按钮，也可以直接「开始学习」。也可直接开始一个尚未细分的章节。已创建的层级不会重复添加，不设固定细分层数上限。结构化输出验证通过后，章节标记、规划对话和课程状态在同一数据库事务中保存，失败可以重试。

每个章节具有独立的讲义和答疑。生成讲义时注入整门课程的符号约定、章节位置、课程地图、用户确认的共享笔记，以及其他章节已生成讲义的限长参考。参考最多 24,000 字符、每章最多 6,000 字符；原始答疑内容不会自动进入其他章节。它减少符号不一致，但不能保证模型永远无误；用户编辑的共享符号约定优先于 AI 新建议。讲义正文的严谨性仍需按实际学科内容检查。

网络层支持 HTTP_PROXY/HTTPS_PROXY/NO_PROXY，连接超时增至 30 秒；只对连接建立阶段的临时故障重试一次并尝试 IPv4，不重试 HTTP 错误或中断的流式响应。诊断日志仅包含域名、错误码和尝试次数，不记录密钥、请求头和正文。DeepSeek 模型检测不再使用 OpenAI 模型；短连接测试改用 128-token 预算并关闭 thinking，且将空正文判为失败。当前 DeepSeek 聊天也使用 non-thinking 模式以兼容既有工具链。

真实 API 集成检查可显式运行 `BRANCH_MIND_LIVE_TEST_CONFIG=/private/path/config.json npx vitest run src/__tests__/integration/liveCurriculum.test.ts`；该文件仅在授权时提供，不放入项目。默认测试不会调用付费 API。测试报告仅保存在开发者本机，发布时排除。

## 0.1.1 学习背景与继续细分

创建课程必须填写学习目标和已有基础；目标与基础保存在课程数据中，规划、讲义和答疑都会使用，备份和同步也会保留。已有课程无需重建：在「笔记规则」中补填这两项并保存。它们用于调整先修知识和讲解深度，不代表已验证学生掌握程度。

移除了固定层数和 500 分支总数限制，旧版本标为 leaf 的章节也能继续细分。若模型返回空子节，本次不修改数据，界面允许重试或开始学习。已有子节的章节会显示子节列表，选择一个子节继续向下展开。很深的树只限制视觉缩进，节点本身不会被隐藏。实际大小仍受浏览器存储、模型上下文和同步 20MB 限额约束。

严谨讲义按教材条目组织；该提示词影响后续生成，不自动改写旧讲义，也不能替代学科正确性审核。
