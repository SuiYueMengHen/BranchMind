# Security and privacy

Never post credentials, private conversations, or study backups in a public issue. For sensitive reports, use GitHub private vulnerability reporting when enabled, or the repository owner's private contact channel.

Version 0.1.x is the currently supported release line. This is a personal study workspace, not a multi-tenant service. The model/tool server can access credentials and request content. Configure authentication and HTTPS before remote access; sync is not end-to-end encrypted.

Backups omit provider credentials but preserve text verbatim. Secrets typed into messages must be removed before sharing. A public repository should contain source and fictional fixtures only. Rotate any credential that was accidentally made public.
